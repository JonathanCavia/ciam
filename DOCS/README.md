# Documentación

Los planes de trabajo se mantienen en [`PLANS/`](PLANS/README.md). Antes de implementar un conjunto de cambios de producto, consulta el plan aplicable.

Cada conjunto de funcionalidades debe tener un plan que describa el objetivo, el alcance, los criterios de aceptación y el mapa de archivos previsto con el motivo de cada cambio. Una persona debe revisar y aprobar el plan antes de comenzar la implementación.

Actualiza el plan si cambian el alcance o los archivos previstos. Al completar el trabajo, registra los archivos modificados, la verificación realizada y la revisión humana.
